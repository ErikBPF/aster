ASTER — VISUAL IDENTITY STARTER KIT v1.0

Start here: guide/index.html (self-contained offline guide)
Quick overview: guide/aster-identity-sheet.png

svg/aster-master.svg is the transparent primary vector source.
All wordmark letters are editable SVG paths. No installed fonts are required.
The wordmark and star are separate named groups for recoloring.

VARIANTS
aster-color-dark: white lettering + lavender star, transparent; use on dark backgrounds.
aster-color-light: midnight lettering + deep-violet star, transparent; use on light backgrounds.
aster-monochrome-white: pure white, transparent.
aster-monochrome-black: pure black, transparent.
aster-midnight: primary colors on a solid midnight rectangle.
PNG versions are 1720 x 512 px (2x the SVG display dimensions).

ICONS
Isolated star in lavender, deep violet, white and black, as SVG and transparent 512 px PNG.
Rounded midnight app tile as SVG/PNG. PNG favicon sizes 16, 32, 48, 64, 180, 192, 512.
favicon.ico contains 16/32/48/64 px variants.
site.webmanifest references files in the same icons folder. Adjust paths for your deployment.

USAGE
Keep the diagonal cut on A and the raised star. Do not change proportions.
Clear space: one full star diameter beyond the artwork on each side.
Full wordmark: recommended minimum width 160 px. Star: use for small icons.
Keep the star one solid color. No gradients or glow are needed to read as a bright star.
Digital palette: Midnight #041F43 / Starlight #C3C0FF / Deep violet #6658B8 / White #FFFFFF.
Deep violet is the stronger-contrast alternate for light backgrounds.
brand-tokens.css provides optional product UI tokens.

FIDELITY
This is a clean, hand-built vector reconstruction from the selected raster concept,
not an embedded bitmap or an exact recovery of the source font. Curves and star arms
were normalized. No third-party font file is included or required for the logo.
Print-specific color matching and trademark clearance are outside this starter kit.
